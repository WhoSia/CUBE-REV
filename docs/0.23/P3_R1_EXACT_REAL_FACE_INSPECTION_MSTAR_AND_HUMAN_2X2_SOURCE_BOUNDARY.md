Rather than assume one observed human ability level for the 62 states, pre-register the exact finite conditional problem [before the new CI outcome](../../data/cuberev-023/p3_r1a_preregistered_physical_face_query_dictionary_frontier.json):

- **Fixed candidate cohort:** deterministically select the **lexicographically first largest** 62-member CP/CO-identical fiber out of the entire exact original radius-5 3×3 full cubie ball. No picking human-looking or conveniently tractable scrambles after observing policy outcomes.
- **Fixed action class:** only the **18 actual legal outer face HTM turns**, in a fixed URFDLB original frame. A source state reached in up to five true HTM actions has a real exact inverse witness of at most five actions.
- **Two separately declared goals:** G_corner = solve original **eight corner positions + orientations**, ignoring edges; G_full = solve all original 3×3 **corner+edge positions+orientations** exactly (not just rotation-equivalent). Crucially, **changing the goal alters the task R**, so this is *not* evidence that one fixed requirement's M* changed merely with human cognitive capacity.
- **Observation class:** corner-only CP/CO initial observation for all 62 states is identical; additional operations query **all 9 true color stickers on ONE actual original cube face**, choosing among six face identifiers. This is an **ideal fixed-frame full-face oracle**; not a reported human visual glance, per-sticker attention, or WCA competition inspection time.
- **Resource axes:** number of permitted full-face queries q=0..6; policy fixed-set vs answer-adaptive sequential face selection; dictionary cardinality K distinct legal complete solution words; exact success on all or, where explicitly marked, success under an **artificial uniformly weighted 62-state cohort**.

## 3. Exact finite face-observation resource frontier: fixed vs adaptive

For each of the 62 physically derived original states, store every one of the **six original 9-sticker face-color words** in deterministic face-position order. All complete six-face signatures uniquely identify the 62 true states. Two independent mathematical enumeration schemes:

1. **Fixed-face subfamilies:** exhaustively evaluate ALL `2^6=64` possible unordered face subsets and count actual physically distinguished state-equivalence classes. Enumerate *all* minimum fixed face sets that identify all 62.
2. **Adaptive minimax face decisions:** exact state-mask dynamic programming over all 62 true cubie witnesses and six unobserved face options, recursively choosing a face and partitioning the true candidate subset by the nine-sticker answer, minimizing worst-case future face queries. Recursively replay every leaf of the chosen tree and verify it ends in exactly one source state, then apply that state's actual 18-HTM ≤5 complete inverse solution.

**Result: minimum worst-case additional full-face reads for exact G_full identification is 4, both fixed and adaptive.** No one-, two-, or three-face adaptive policy can guarantee selection of a correct full 62-way solver in this model.

All **four** optimal four-face fixed observation sets, in the pinned original frame, are `URFB`, `RFDB`, `UFLB`, and `FDLB`. No other smaller fixed subset is injective.

The table counts **distinct observation leaves / states correctly solvable** under the *explicit uniform 62-state prior* if each leaf is assigned one source-specific full solve word; it is NOT a claim about the fraction of real-world competitors who would solve. This is a genuine **adaptation advantage under q=2 and q=3**, while both strategies share the worst-case full-cover guarantee q*=4. The constructed one minimax policy has a **mean 2.806451612903226 face queries** under synthetic uniform weighting, not a globally proven minimum-expected-query policy. The adaptive minimax solution was independently replayed against all 62 actual 54-sticker cubies.

For each integer full-word library budget K in `{1,2,4,8,16,32,62}`, exact maximum uniformly-weighted correct states under adaptive at-most-q query budget is:

`success_count(q,K) = min(K, adaptive_distinguishable_leaves(q))`.

This identity holds here because (i) every genuinely distinct exact full state needs a distinct full-solving word, and (ii) an observation leaf can solve at most one state with its chosen word; both converse construction and upper bound are provided. It does NOT express actual estimated human recognition or memory.
