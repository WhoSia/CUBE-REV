## Explanandum lock

Given a finite state space X, a reversible transformation group G generated by an admissible action alphabet A, an observation partition O:X→Y, and a target z∈X, derive structural conditions controlling

1. **diagnosis:** minimal adaptive observation-action length to distinguish an unknown initial state;
2. **reset:** minimal adaptive action length to steer all possible initial states to z;
3. **history reconstructibility:** multiplicity of literal action words compatible with observed endpoints;
4. **constrained experiment dictionaries:** size and complexity of finite open-loop word catalogues for distinguishing specified source subsets.

A theorem counts as new 0.17 science only if it changes quantifier scope, proves a transferable invariant, generalizes across a second action/observation system, or supplies a sound new lower bound not equivalent to a frozen 0.16 certificate.

## First 0.17 mathematical transfer — model-class return bound

The new [Return-Maximality Theorem](RETURN_MAXIMALITY_THEOREM.md) extends the 0.16 P8 return-collision argument from the specific 24-state octahedral edge graph to any **symmetric reversible action-count matrix B** whose powers have equal diagonals at the relevant horizon. At every EVEN length t, `B^t` is a Gram matrix and same-state return is a maximum endpoint history fiber; at EVERY length this holds if `B` itself is positive semidefinite. A reversible two-state swap gives a concrete counterexample at ODD t without PSD, showing why the extra assumption is real. This is classical Gram/Cauchy–Schwarz theory applied with precise quantifier conditions, not a claimed novel global inequality. The next nontrivial frontier is coarse observation partitions and adaptive policy bounds, not enumerating more instances of this lemma.
