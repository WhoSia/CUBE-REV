## Scientific observation model — do not blur

Our fixed-state experiment uses a subset S of the *20 original oriented cubie tags* of the physical fixed-centre 3x3 cube. For states x,y in B_r (the 18-face-turn HTM radius-r ball), a tag reports its **original labelled cubie's full position and orientation**. A selected set S is valid if all states in B_r have distinct observed vectors. This is equivalent to a pointwise stabilizer H_S containing no nontrivial element in B_(2r), with the fixed group-action convention.

This is NOT the standard graph resolving set: a landmark there reports the **distance to a graph vertex**, not the orientation and position of a tagged cubie. It is NOT a classical full permutation-group base: that requires a globally trivial stabilizer. It is NOT general fault-tolerant metric dimension: that deletes landmarks from graph-distance vectors. It is NOT adaptive FSM distinguishing sequence testing: actions and outputs are sequentially selected.

## The paper novelty threshold

**Classical / inherited (do not claim as new):** any finite group-action base notion, stabilizer index or order; standard 3x3 cube parity/orientation constraints; two-variable inclusion-exclusion; Cayley/Johnson/line-graph properties; generic failure of matroid exchange; generalized fault-tolerant metric dimension; graph automorphism symmetry; FSM preset/adaptive distinction.

**CUBE-specific finite deductions (new in this project, external novelty not established):**
- Exact original-cubie B6 minimum 16 with 156 verified sensor layouts under historically archived physical certificate assumptions.
- 2-corner/2-edge stabilizer S3 × C2; common pure-corner C3; 88 entries ->74 distinct goals algebraically; 74->41 additionally requires inverse and cube spatial symmetry.
- Concrete exchange axiom failure for B6 optimal 16-tag sensor sets.
- Entire 156-layout single-original-tag exchange graph: 25 components, sizes 96 + twelve 4 + twelve 1; 336 edges, 264 fixed-corner +72 cross-corner edges. This is an exact finite combinatorial result conditional on historical B6-positive membership evidence.

**OPEN independent proof gates before any journal-ready factual novelty claim:**
1. A truly separately implemented physical cube transition semantics replays the key 41 B6 goals and all named negative swap witnesses.
2. A verifiable certificate of geodesic exclusion in the original 18-HTM alphabet beyond sharing a single facelet engine.
3. Explicit page/section comparison against full Boutin (2009) and subsequent exchange-graph/matroid basis literature; inspect whether related cube problems were already published.
4. Contextualization of finite exact B6 results versus broader radius-restricted object-identification theory; careful not to relabel distance-landmark problems as equivalent.
5. Preserve 0.27 global no-17 lower-bound open/conditional status; 0.18 M* dictionary bounds are a separate model.

**Scientific judgment:** the short-term valuable research is a proof-carrying, physically grounded combinatorial case study. The possible publishable contribution is NOT a general graph-theoretic exchange discovery, but a sharply specified cube-legal, bounded-word-metric identification model with exact B6 thresholds, concise incidence classification and independently checkable physical certificates.
