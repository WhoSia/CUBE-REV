### Close-reading judgement

Moore's text explicitly permits a next experiment input to depend on prior outputs. Adaptive interrogation itself is classical prior art. Buhrman–de Wolf investigate deterministic decision tree depth, per-state certificates, sensitivity, block sensitivity and polynomial methods for Boolean bit-queries; this cannot be quoted as a proven lower bound for a 36-valued paired cube observation with correlated outputs and parity-constrained state domain. Soucha–Bogdanov's splitting-tree extensions produce useful separating sequences for state subsets, but do not inherently minimize a full adaptive cube decision tree. The two Hierons–Türker distributed-testing papers impose physical or protocol controllability requirements that our current centrally coordinated two-port cube model does not. These distinctions belong in Paper B's previous-work section.

## 4. Parallel formal proof development

**P8.9, prior P6.2 posterior covariance:** Lean 4 source in [ObservationCovariance.lean](../../formal/028/ObservationCovariance.lean) proves at the *abstract mathematical relation* level that inverse-mapped belief membership and each literal observed posterior are preserved under a bijection satisfying exact spatial-query covariance. Feasibility of each categorical response is preserved in both directions. It also formalizes the arithmetic consequence 1<=21-h<=3 conditional on inherited numeric certificate assumptions. It does **not** prove a proposed map is legal in physical P48 or that each of 576 query routes is valid.

**P8.10, prior P8.3 adversary:** Lean 4 source in [TwoStepAdversary.lean](../../formal/028/TwoStepAdversary.lean) formalizes the correct logical order: for every first query, an actual feasible first response exists such that for every second query two still-possible distinct states share the second response. This condition excludes all two-read adaptive identification policies. It does **not** verify the original 384 first-query, 2,304 pair raw physical witness ledger; that is a separate data-to-kernel bridge.

Both sources use isolated [Lean 4.34.1 package](../../formal/028/lakefile.toml), its pinned toolchain, and read-only [Actions kernel workflow](../../.github/workflows/cuberev-r14-p89-lean-observation-covariance.yml). **No kernel-success result was observed at report authorship; classification SOURCE_PENDING_KERNEL.**

**Independent regression test** in [audit_r14_p89_p810_generic_transport.py](../../scripts/cuberev-observation/audit_r14_p89_p810_generic_transport.py) uses an intentionally much smaller 64-state, 9-paired-query binary model. Actual local standard-library execution passed: 389 nonempty reachable belief masks, 14,004 observation-fiber covariance test triplets, 81 valid online two-step collision witnesses, 64 distinct signatures from a three-read fixed policy, and equal-cardinality/different-response-profile negative control.
