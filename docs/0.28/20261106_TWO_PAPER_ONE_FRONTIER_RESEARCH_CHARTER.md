## Short-cycle execution discipline

1. **One central question per court.** State the exact model, universal quantifiers, allowed physical actions and one measurable success/failure criterion.
2. **Construct two routes:** a mathematical argument and a source-independent computation or counterexample. Distinguish the independent nature of each route precisely; scripts importing the same P48 generator are regression tests, not independent geometry reconstructions.
3. **Use anytime falsification:** test all legal-generator invariants, half-known edge/color matchings, parity opposite cases, spatial/original orientation conventions, small exhaustive negative controls, and relabeled counterfactual histories. Stop immediately when a false proof shortcut is detected; commit an erratum rather than burying it.
4. **Preserve meaning and bytes:** GitHub executable research branch, Drive immutable raw Python/code, actual execution receipts, Notion theorem decision, citation/novelty audit; never allow github-actions[bot] source authorship.
5. **Commit coherent scientific units**, not artificially split commits; explicitly mark LOCAL_PASS / BYTE_VERIFIED / REMOTE_CI_PASS / INDEPENDENT_PHYSICAL_PASS / PROVED / OPEN separately.
6. **End each cycle with PI judgment:** theorem gained, obstacle not removed, exact remaining logical obligation, next single experiment most likely to change the decision.
