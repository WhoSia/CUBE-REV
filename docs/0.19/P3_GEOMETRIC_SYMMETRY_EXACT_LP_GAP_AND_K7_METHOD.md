## Exactly 16 incidence automorphisms induced by signed cube-coordinate permutations
Using edge-slot coordinates of the physically sticker-derived cube, allow either (x,y,z) -> (±x,±y,±z) or (x,y,z) -> (±y,±x,±z). There are 16 maps. **Some are orientation-reversing reflections, not legal moves; the claim is an automorphism of the incidence optimization problem, NOT that all 16 transformations are physically executable.**

For every one of the 16 maps, explicit finite checks established:

2. All 8807 physically realized inclusion-maximal length-five coverage types are permuted bijectively.

This gives a genuinely equivalent 42x196 *fractional LP* orbit formulation by averaging feasible vectors over the finite group. It does NOT give an equivalent 42x196 binary integer set-cover formulation: averaging a 0/1 vector generally produces fractions.

### Sound integer SAT symmetry breaking
Let R be the set of 196 column-orbit representatives. Every nonempty cover D can be transformed via one group automorphism so that at least one selected experiment becomes an element of R. Thus the Boolean clause

```

One must NOT collapse all orbit variables into one Boolean variable.
