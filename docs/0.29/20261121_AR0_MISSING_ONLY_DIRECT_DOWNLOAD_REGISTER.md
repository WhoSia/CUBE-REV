## C. Download and provenance procedure

For a URL explicitly marked **direct PDF**, open the link in a browser and save the file. For a landing/DOI/publisher catalogue URL, inspect its downloads; if the journal provides none, use its official contact route or institutional library access. Never imply a DOI or volume table of contents directly serves the original PDF.

When the user uploads an actual new PDF into Research OS `00_INTAKE`, verify its **raw bytes and SHA-256**, journal cover/first/last page, exact author-title-year-page and whether it is an original publication or an author manuscript. Only then rename and place it in `10_PAPERS` (or `11_SOURCES` for books/theses), update the project-wide missing register and add a Notion custody receipt. Do not overwrite the dated historical 2026-11-11 gaps.
