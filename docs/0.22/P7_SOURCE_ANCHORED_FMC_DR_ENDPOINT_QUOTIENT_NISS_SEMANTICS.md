## 5. Actual NISS group semantics with source-based typed side operations

For a scramble group element S, let A be the chronological concatenation of normal-side turns and B be the chronological concatenation of inverse-side turns. In a common physical group frame define:

\[
N(B,A)=B^{-1}SA,\qquad
N(B,A)^{-1}=A^{-1}S^{-1}B.
\]

A normal-side turn a transforms N to N a (right action). An inverse-side turn b transforms N to b^{-1}N (left inverse action). Closing the loop is N=identity, in which case the normal-scramble solution is **A B^{-1}**. In general a parenthesized inverse-side word cannot simply be appended after A as an ordinary normal-side prefix. This is classical NISS group manipulation, not a new group discovery: [Richard Taylor's detailed FMC NISS explanation](https://richardtaylor.co.uk/threads/cubing/fmc-niss.html) and [Nissy's open-source state conventions](https://github.com/sebastianotronto/nissy-classic).

Replaying N(B,A) using genuine full Rubik physical moves closes the loop and reconstructs **exactly the authored final 19-turn solution**. This shows the algebra is consistent but it is explicitly NOT a claim either actual competitor switched sides at that point.
2. **Source parenthesized inverse candidate:** from [Miao Final Attempt 2](https://333.fm/wca/reconstruction/FMCWorld2026/2014MIAO02), lines 74–83, store the typed normal EO/RZP prefix and an authored *parenthesized* alternate inverse-side segment **F2 R2 D R2 D**.
