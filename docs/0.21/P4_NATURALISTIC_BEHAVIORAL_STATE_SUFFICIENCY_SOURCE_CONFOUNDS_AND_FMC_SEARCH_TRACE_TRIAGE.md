**Interpretation:** The comparison **loses common-key SAME vs DIFFERENT support already after stage matching**. The remaining one strict pair is a different-corner-state pair. A final `ΔD` is mathematically undefined for the strict endpoint because there is no SAME-state denominator. Do not describe the absence of disagreeing pairs at strict levels as a successful explanation or a human deterministic policy.

Frame implementation: a signed basis with 24 proper cube rotations, each observed `x/y/z` composed as a local-axis operation on the right. Tests include inverse closure, half-turn closure, noncommutation, and **24 possible signatures**. It is **only a proxy for explicitly transcribed rotations**: cumulative human viewpoint, unreported regrips, and source notation conventions were not independently observed. A prior exploratory left-composed coordinate model had intermediate counts 149/64/9; the corrected right-composed counts above are authoritative. The original FC3 observation/sticker results are unaffected.

The stage variable is the last `annotation_after` on a preceding step with `boundary_after=true`; it is a **proxy for author-stated stage boundary**, not a verified human cognitive phase or time-stamped transition. 24,407/25,272 decision rows have *some previously encountered stage label*, which is not proof of genuine contemporaneous phase observation. Only 1,120/25,272 rows have an explicit `method_family` in this particular archival JSON (815 CFOP, 262 Roux, 43 ZB); all other 24,152 are UNCLASSIFIED rather than silently inferred. Prior recovered supplemental method tables may improve this field but were **not joined in P4**. This blocks strong method-stratified claims.

### Video escalation gate

Use video only for an **identified missing observable**, such as a real-time sequence of discarded candidate branches, clock-timed pauses, revisions or visual object inspection. A tutorial or after-the-fact reconstruction is **not** equivalent to uninterrupted performance. Require exact video URL/title/source and participant linkage, unedited segment/timestamp checks, platform rights review, double annotation where feasible, `UNKNOWN` for occluded events, and a distinction between `VISIBLE_OPERATION`, `AUDIBLE_SELF_REPORT`, `POSTHOC_EXPLANATION` and `AI_INFERENCE_NOT_AUTHORITY`. Current review did not establish an accessible continuous FMC World 2026 attempt video linked to those retrospective cases; **no footage downloaded or labeled**.
