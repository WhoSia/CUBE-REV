## Full typed physical solver contract

Let A be exactly the 18 legal original outer-face moves in half-turn metric, and H={U2,R2,F2,D2,L2,B2} be a **subset of actual A**, not an idealized human move. All states are **complete actual ordered 54-sticker strings** generated by legal 3D positions, outward normals and original stationary-center frame.

Precompute by actual physical BFS:
- **R4:** all full18 states at true whole-cube d18<=4. Exactly **46,741** states, shell sizes 1/18/243/3240/43239. Each entry stores a replayable shortest word from solved; inverses yield an exact whole-cube solution.
- **H5:** all half-turn-only states at true dH<=5. Exactly **2,605** states, shell sizes 1/6/27/120/519/1932. Each entry stores a replayable shortest H word.
- **No other solver cache.** The entire full18 R5 cohort of 621,649 states and the complete H subgroup of 663,552 states are **offline evaluator oracles for ground-truth benchmark labels only**. They are not available to the deployed R4/H5 query algorithm; their time/space must not be hidden in a deployment cost claim.

The claim of a **guaranteed complete optimal solve applies ONLY to the d18<=5 ball**. A source state outside R4 is known to have d18>=5. If exact H5 lookup produces a real legal five-move halfturn solution, then d18<=5 by replay. Hence **d18=5 exactly**, and the solver may emit this H solution without any full18 neighbor expansion. Otherwise it examines each of 18 real legal successor face turns and tests membership in the exact R4 table. If a successor of distance <=4 is found, output that move plus the inverted exact goal-path word. Since d18>=5 and a <=5 solution exists, this is again globally shortest. If no successor is in R4, output **HOLD_OUTSIDE_RADIUS5** — not a false claim of unsolvability or a globally solved cube.

**Proof of coverage:** Every actual d18<=4 cube is in R4. For any d18=5 cube, a globally shortest legal first move reaches a true d18=4 neighbor in R4. Thus the ordinary 18-successor fallback always finds a shortest five-move solution for any source in the fullR5 ball, independent of H subgroup membership, source author or reconstruction stage.

**Proof of safety:** The only special shortcut requires *an actual full 54-sticker H-word witness of length exactly five*, plus independently established nonmembership of R4. This implies exact d18=5 by sandwich. An H word of length eight or nine is NEVER a valid lower bound on unrestricted d18 and does not license stopping.

## Actual cubie orbit screening (P1-R1 second intervention)

Before any H5 lookup, use the genuine twelve **two-sticker edge positions** to check physically possible paired sticker colors under H moves. For each edge position, the H5 table itself supplies exactly four allowed genuine color-pair signatures. A fixed ordered set of twelve 36-entry byte masks validates these signatures; the masks use only the actual original 54-sticker source configuration and physical H5 precomputation, **never the evaluation-only HGroup ground-truth labels**.

**Formal safe rejection:** If an actual state belongs to H5, its per-position two-sticker signature must be present in the corresponding four-pair set by construction. Hence a failed signature cannot exclude an H5 certificate; it can only avoid an unnecessary H5 hash lookup. Passing the filter does not authorize claiming membership, a five-move H solution, or any human intent: an actual exact lookup and matching source-state full-sticker replay are still required.

Original complete 663,552-state H group evaluation independently verified that the twelve allowed edge-pair patterns coincide with globally preserved real H edge tetrads. A stronger entire-H membership claim is not needed for algorithmic *no-false-negative H5 screening*.

For all **574,908** physically distinct full18 exact-distance-five states:
- Exact H5 five-move certified source states: **1,932**.
- Full-source states passing the real 12-edge-signature gate: **2,124**.
- Gate-positive but H5-five certificate absent: **192** (the P1-R0 genuine H-geodesic 8/9 counterexamples).
- Gate-negative source states: **572,784**; all avoid H5 table lookup and remain eligible for the complete full18 fallback.

These counts are **complete original physical state enumeration**, not sampled estimates. The finite gate equivalence is asserted on the fully enumerated d18=5 cohort only, never all 3×3 states.

## Fixed baseline, precomputation costs, metrics and empirical audit

**B0 (fair baseline)**: R4 original physical full18 BFS cached, then original 18-successor complete radius-five probe.  
**B1 (naive H5 dispatch)**: same R4 cache **plus** 2,605 H5 states; check exact H5 source membership before B0 fallback.  
**B2 (orbit-screened H5 dispatch)**: same R4+H5 caches, but examine physically computed twelve-edge masks first and do not query H5 unless the necessary edge orbit condition passes.

All three programs use **the same original 54-sticker move engine, the same outer-face move order, the same complete R4 resource, the same legal HTM goal and actual full-sticker solution verifier**. B1/B2 pay H5 precomputation and extra memory. Offline labels from the full physical H group and full radius5 ball cannot be used by B0/B1/B2 at query time.

An initial **retrospective pilot**, directly executed on a local Node.js 22.16.0 x86_64 Intel Xeon Platinum 8573C environment (five exposed vCPUs, ~5.8GiB system memory), gave shared R4 precomputation **~168-183ms** across runs, extra H5 precomputation **~7.7-8.2ms**, and extra measured Node heap **~0.96MiB** after GC for H5. Exact results may vary by runtime, garbage collection and hardware; these are not stable cross-machine constants.

Three source cohorts:
1. **1,932 whole-cube H5 states of true global d18=5**, exhaustively selected. B0 has 20,007 table probes and 18,075 actual new 54-sticker source-neighbor move evaluations. B1 and B2 each have 3,864 table probes and **zero** source-side neighbor move evaluations, and physically solve every state. Thus B2 reduces source query probes by **80.7%** and actual source-side legal turn computations by **100%** within this category. In one five-repetition local pilot, B0 median about **37.8ms** vs B1 about **1.3ms**; B2 separately measured around **1.26ms**. A retrospective specialized-cohort speed result is not cross-ecology superiority.
2. **192 real physical global-five/H-eight-or-nine distortion adversaries**, exhaustively selected. B0 probe count **1,056**, B1/B2 **1,248**: **18.2% more**. All use full18 fallback and return verified true 5-move original facelet solutions, NOT suboptimal H words. Timing in this small cohort was noisy; no credible speed gain is claimed.
3. **4,096 out-of-H original source states** drawn via seeded xorshift32 reservoir 0xC0BE2026 from the entire **572,784** non-H global-five states, and physically replayed to solved. B0 has **40,505** table probes, naive B1 **44,601** (+10.1%), but **orbit-screened B2 restores 40,505**: it rejects all 4,096 samples before H5 lookup while preserving full18 solutions. The cohort was selected in the pilot; its next repetition is not a new prospectively blinded sample. The actual wall times of B0/B2 were both in the ~70-80ms range with order/JIT/GC variation; do **not** claim robust statistically significant wall-time superiority.
