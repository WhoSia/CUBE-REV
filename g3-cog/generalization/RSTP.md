# Reversible-State Transposition Paradigm (RSTP)

RSTP is a prospective experimental-design family, not a universal cognitive law and not a renaming of provenance/transportability theory.

A task is RSTP-admissible when it supplies a physical state space `S`, an action vocabulary `A`, an exact transition rule `F`, an outcome-blind history-context functional `Z`, and a probe action surface. The primary object is a transposition pair

`F*(s0,hA) = F*(s0,hB) = s*` while `Z(hA) != Z(hB)`.

When both histories end in the same nonempty suffix `c`, write `hA=uA c` and `hB=uB c`. For reversible/injective suffix dynamics, equality after `c` implies equality before `c`, providing a recency shield rather than a mere endpoint match.

## Minimal admission contract

1. Exact same physical probe state under an authoritative serializer.
2. History/context labels computed before behavioral outcomes.
3. A nonempty common suffix when recency is a live rival.
4. Matched or prospectively bounded history burden.
5. A nondegenerate probe action surface with at least two admissible continuations.
6. Representation support may change available information but not physical state or action legality.
7. A state-only control family and a context-divergent family are both required.
8. Browser/instrument validity is separate from cognitive validity.

## Scientific estimand

The broad estimand is not `history matters`. It is whether action selection in an exact transposition obeys

`P(a_next | s*, h, R) = P(a_next | s*, Z(h), R)`

in a way that distinguishes state-only, contextual-trace, hierarchical-control, and representation-maintenance rivals.

## Domain relation

- Cube is the first high-constraint instantiation because exact reversible transitions and transpositions are computationally auditable.
- The executable 5x5 torus witness in `torus-witness.mjs` is a non-Cube positive control showing that the compiler contract is not cube-specific.
- Candidate future domains include reversible graph navigation, edit/undo tasks, assembly/manipulation tasks, and fully specified game transpositions. Domain transfer is not licensed until the task state includes every variable required for Markov sufficiency in that domain.

## Anti-slop boundary

RSTP does not claim that all history dependence has one mechanism. It does not treat an exact transposition as proof of latent options, memory traces, or hierarchical plans. Generalization is earned only when a second domain preserves the formal intervention and produces rival-separating predictions before outcomes are observed.
