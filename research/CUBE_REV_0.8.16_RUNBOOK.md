## Determinism

Run the 0.8.16 analysis twice into separate empty directories and compare recursively. All generated bytes must be identical. Generate `ARTIFACT_SHA256SUMS.txt` only after all evidence documents have been copied into the artifact directory, and exclude the inventory file itself from its input list.

## Key assertions

- six rotationally unique families;
- at least four distinct certified parent states;
- every generated seed equals its parent after exactly the recorded generator move;
- at least six recovery opportunities per family;
- 36 probes with planned and error face counts of six each;
- exact 24-rotation × 18-move conjugation;
- 12 unique schedules with family spacing at least six;
- first-action open/closed and recovery contrasts below 0.60;
- two-action-plus-latency contrasts above 0.80;
- identical latent negative below 0.60;
- all action-slip/latency-noise robustness conditions pass;
- matched public reconstruction pair has the same scramble and time but distinct routes;
- WCA source is treated as an outcome/scramble anchor, not a trajectory source;
- no participant route or production file changes.

## External-data promotion gates

Before bulk external ingestion:

1. acquire the exact versioned WCA archive;
2. record archive SHA-256, export metadata, and attribution;
3. create an immutable raw snapshot of any permitted public reconstruction corpus;
4. document robots/terms and request permission if automated bulk retrieval is not clearly allowed;
5. keep smart-cube data owner-consented;
6. run the exact/ambiguous/unlinked adjudication court;
7. prohibit named-person latent-trait inference.
