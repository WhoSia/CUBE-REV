# G5-P4-R3 — Controller-State Allocation Law

## Explanandum
R3 generalizes the one-bit R2 result to multi-bit recovery targets.

For a k-bit XOR-vector recovery target, the exact observation-history quotient has 2^k terminally distinguishable classes. A deterministic controller that must output the full target therefore needs at least 2^k distinguishable internal states when no external scratch is available.

## Allocation law
Let s of the k target bits be carried by reversible external scratch.

The constructive split controller uses:
- internal states = 2^(k-s),
- external scratch states = 2^s,
- joint controller-world states = 2^k.

Hence:
- internal memory bits = k-s,
- external scratch bits = s,
- internal bits + external bits = k.

For this XOR-vector family the lower bound is exact, not merely sufficient: if all 2^k target values are reachable and the external scratch exposes at most 2^s states, at least 2^(k-s) internal terminal states are required by pigeonhole.

Therefore the minimal scratch required to meet an internal-memory budget b is max(0,k-b).

This is a family-specific allocation law. It is not asserted for arbitrary recovery tasks.

## Cross-target controller lattice
Nested targets T1..T5 are formed by projecting a five-bit target vector onto its first k coordinates.

The quotient therefore refines monotonically:
2, 4, 8, 16, 32 target classes.

Transport is only authorized when the target projection itself is preserved.

## Cube-derived factorization
The seven-corner permutation produces the 21 pairwise inversion observations.

Five binary target coordinates are defined:
1. full inversion parity;
2. parity of inversions involving position 0;
3. parity of inversions within positions 0..3;
4. parity of cross inversions from positions 0..2 to positions 3..6;
5. parity of adjacent-position inversions.

Each inversion observation contributes a fixed five-bit membership mask. The controller XOR-accumulates these masks.

R3 checks all 5,040 permutation representatives and a distinct orientation-coded state from every permutation block.

Required results:
- T_k realizes all 2^k target values for every k=1..5;
- T_k equals the low-k projection of T_5;
- every internal/external allocation s=0..k exactly recovers T_k;
- orientation changes do not change the permutation-derived stream.

Because each target value occurs in the cube-derived family, the terminal-output lower bound is exact for this target projection as well:
with s external bits, at least 2^(k-s) internal states are necessary.
