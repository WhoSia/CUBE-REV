# CUBE-REV Generation V G5-P4 Constitution

**Formal stage:** CUBE-REV Generation V G5-P4 — Pareto-Optimal Recovery Protocol Synthesis, Active Information–Computation Co-Design, Learned Policy Compression, Adversarial Failure Localization, Bounded-Agent Executability & Hybrid-Agent Composition Court

## Inherited authority
G5-P3 is frozen as the recovery-surface analysis court. P4 may consume its finite recovery semantics but may not rewrite P3 witnesses, transport verdicts, provenance, or authority ceilings.

## Primary explanandum
P4 changes the question from whether a target is recoverable under a frozen intervention/observation regime to which adaptive protocol trees recover it under explicit resource constraints.

The primitive object is therefore not a scalar score but a set of non-dominated protocols:

`Pi*(W,tau,Omega)=ParetoMin{pi : pi recovers tau}`.

No weighted sum is canonical unless separately justified.

## Resource coordinates
The initial exact implementation carries four explicit coordinates:
- query cost,
- external-action cost,
- internal-operation cost,
- memory cost.

A protocol is executable only relative to a declared resource budget. No bounded-agent or human-executability claim follows from finite-machine solvability.

## First implementation court
P4-R0 materializes:
1. exact adaptive policy-tree synthesis over finite P3 worlds;
2. worst-case resource accumulation;
3. Pareto pruning without scalarization;
4. bounded-budget feasibility filtering;
5. structural policy size/depth measures for later learned-compression courts;
6. adversarial failure localization as loss of budget-feasible recovery under a perturbed world.

## Learned-policy rule
A learned policy is never accepted because it is smaller, faster, or empirically accurate on development cases alone. Later learned-policy courts must compare against exact synthesized authority on held-out worlds and preserve explicit falsifiers for target error, resource overrun, and transport failure.

## Hybrid-agent rule
Hybrid composition is a later P4 court, not assumed complementarity. It must beat the union of single-agent feasible frontiers under a predeclared joint resource accounting scheme. Mere division of labor or access to more resources is not complementarity.

## Adversarial rule
Adversarial failure localization asks which perturbation removes previously feasible recovery and which resource or information dependency is responsible. It does not infer cryptographic hardness from failure in a finite search court.

## Forbidden upgrades
This stage alone does not authorize:
- human cognitive claims,
- neural representation equivalence,
- cryptographic security claims,
- universal reversibility laws,
- replacement of G4/R2 provenance holds.
