# G5-P4-R1 — Exact Protocol Co-Design Court

## Explanandum
Construct exact recovery worlds in which information acquisition, external action, internal computation, and memory are genuine substitutes rather than four labels attached to one query-depth problem.

## Prior-art pressure
This court assumes rather than renames established work on adaptive information gathering, adaptive submodularity, cost-sensitive adaptive distinguishing sequences, time-space tradeoffs, bounded/resource-rational decision making, and epistemic action.

The candidate CUBE-specific contribution is narrower:
1. keep the recovery target exact and fixed;
2. make acquisition and decoder implementation part of the protocol object;
3. retain a coordinate-wise resource vector rather than a scalar cost;
4. connect unsupported Pareto protocols to bounded-agent executability;
5. require exact recovery verification and explicit counterexample fixtures before transport to cube/human settings.

## R1-A — Naturalized parity workbench
For each n-bit hidden state x with target tau(x)=parity(x), four extensionally exact protocol implementations are admitted.

- BitStream: sequential bit acquisition with a running parity accumulator.
- SnapshotCompute: one full-state acquisition followed by an algorithmic parity decoder.
- SnapshotLookup: one full-state acquisition followed by a finite lookup decoder.
- ExternalFold: reversible XOR-to-scratch actions followed by one scratch observation.

Resource accounting for n>=3:
- BitStream = (n,0,n-1,1)
- SnapshotCompute = (1,0,n-1,n)
- SnapshotLookup = (1,0,1,2^n)
- ExternalFold = (1,n,0,0)

Coordinates are (query, external action, internal operation, peak memory bits).

All four protocols must be exhaustively verified against every n-bit state before their cost vectors enter the frontier.

## Memory-semantic correction
P4-R0 left memory composition underspecified. R1 freezes memory_bits as peak simultaneous capacity, not cumulative memory traffic. Sequential resource composition therefore sums query/action/internal work but takes max for memory. R0 used zero-memory action costs, so this correction does not change its opening results.

## R1-B — Scalarization incompleteness gadget
Three exact protocol-cost witnesses:
- A ProbeSparse = (1,4,4,1)
- B Balanced = (3,3,3,1)
- C ProbeRich = (4,1,1,1)

All three are Pareto-optimal.

Suppose strictly positive linear weights (q,a,c,m) make B no worse than A and C. Memory cancels. Then:
- B <= A implies 2q <= a+c.
- B <= C implies 2(a+c) <= q.
Combining gives 4q <= q, impossible for q>0.

Therefore B is an unsupported Pareto point: no strictly positive weighted-sum objective can select it.

But under the coordinate-wise resource budget (3,3,3,1), B is feasible while A violates action/compute and C violates query. B is therefore uniquely executable under that bounded-agent budget.

This establishes a CUBE-relevant reason to preserve the full Pareto set: scalarization can delete the only executable protocol for a bounded agent.

## R1-C — Dominance reversal fixture
A separate scale gadget compares:
- an unrolled protocol with cost (n,n,n,n);
- a compiled macro protocol with cost (2+ceil(log2 n)) in every coordinate.

At n=2, unrolled dominates compiled.
At n=8, compiled dominates unrolled.

This fixture is not claimed as a natural law. It is a counterexample to any scale-independent protocol ordering and forces transport claims to carry their resource-scaling model.

## Falsifiers
R1 fails as a substantive co-design stage if:
- the naturalized parity protocols collapse to fewer than three Pareto points for n>=3;
- any admitted protocol fails exact parity recovery;
- the unsupported point is dominated;
- the balanced point is not uniquely feasible under its own coordinate-wise budget;
- conclusions require a scalar resource conversion to exist;
- the same conclusions are asserted as human cognition or cryptographic hardness.

## Authority ceiling
Structural finite-world protocol synthesis only. No human result. No neural equivalence. No cryptographic security. No resolution of the inherited G4/R2 provenance hold.
