# G5-P4-R2 — Minimal Recovery-Controller Compilation Court

## Explanandum
R2 asks how much internal controller state is exactly necessary to execute a recovery protocol, and whether world manipulation can move that state requirement from the controller into a reversible external substrate.

## Prior-art surrender
Finite-state controllers for partially observable control, automata minimization, history-state compression, and finite-memory policy synthesis are established areas. R2 does not claim their generic invention.

The retained CUBE question is target-relative and constructive:
1. derive the exact observation-history quotient for a recovery target;
2. convert quotient cardinality into an internal-memory lower bound;
3. construct an extensionally equivalent protocol that stores the distinguishing state externally through reversible world transitions;
4. transport the same controller theorem into an exact 2x2 cube-derived target;
5. judge empirical controller compression against the exact automaton authority.

## R2-A — Observation-history quotient
For a binary observation stream whose target is parity, histories are equivalent iff their accumulated parity is equal.

Two histories with different accumulated parity are distinguished by immediate termination, because they require different outputs.

Therefore the minimal deterministic recovery controller has exactly two internal states:
- EVEN
- ODD

and requires at least one bit of internal memory.

## R2-B — Externalization as state transfer
The externalized protocol replaces the two-state internal accumulator with one reversible XOR scratch bit in the world.

Each update scratch <- scratch XOR bit is an involution.

Internal controller states:
2 -> 1.

External scratch states:
1 -> 2.

Joint distinguishable state capacity:
2 -> 2.

Therefore the exact result is not memory disappearance but state transfer across the controller/world boundary.

## R2-C — Cube-derived transport
The existing cuberev-core 2x2 corner authority is inherited without modification.

For each seven-corner permutation, R2 emits the 21 pairwise inversion bits and defines the target as permutation parity.

Every one of the 5,040 permutation representatives is checked. The observation stream and target ignore orientation by construction; an alternate orientation-coded state from each permutation block is checked to have the same permutation and stream.

Thus the certificate covers 5,040 permutation classes x 729 orientation states = 3,674,160 exact ranked cube states for this target projection.

The same two-state internal parity controller recovers the cube-derived target, while reversible scratch externalization reduces internal memory from one bit to zero.

This is a target-level cube transport result. It is not a full-cube solving result and does not claim cognitive equivalence.

## R2-D — Learned compression against automaton authority
A finite controller is induced from labeled binary histories of length at most three.

The learned controller has two states and is tested on all 5,040 cube permutation inversion streams, which are length 21 and therefore outside the training horizon.

Authority comparison:
- exact minimum = 2 controller states;
- one-state compression is rejected by the distinguishing-history certificate;
- learned two-state controller is accepted only if held-out cube failures are zero.

No neural-representation claim is made.

## Falsifiers
R2 fails if:
- the history quotient requires more or fewer than two classes;
- a one-state deterministic controller can recover parity exactly;
- XOR scratch updates are not reversible;
- externalization reduces internal state without corresponding external state capacity;
- cube transport fails on any permutation representative;
- the learned two-state candidate fails on held-out cube streams.

## Authority ceiling
Structural finite-state recovery only. No human memory measurement. No full 2x2 solve claim. No cryptographic hardness. No resolution of the inherited G4/R2 provenance hold.
